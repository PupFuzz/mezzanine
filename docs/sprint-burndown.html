Remaining is what the board still has open in the lane — the cards in the tables above. Done is what the lane selects and the board has moved OUT of the sprint's open stages. Total is the lane's whole selected population, i.e. the burn-down's denominator, so N of T on a tile reads as progress. A card whose stage this board does not publish is unclassified: counted in the total, never in done, and shown as its own figure — a card this tool cannot place must not read as shipped. Each tile's bar is that lane's progress — done ÷ total — so it fills as the lane burns down; a lane that selects nothing reads empty, never complete; and a lane whose membership filters on the column reads 0 done with an empty bar BY CONSTRUCTION — a card that ships leaves the column, so it leaves the selection rather than crossing to done.
