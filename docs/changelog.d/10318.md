- **card#10318** — **The CI store check measures the same database the tests used.** `tools/ci-store-probe.php`, the MariaDB lane's outside check that a migration or the suite really wrote to the store, now takes its address from the app's own `mysql` connection, so `DB_SOCKET` reaches it exactly as it reaches the app; before, it built `host=DB_HOST;port=DB_PORT` itself, and on a socket-only private mariadbd it measured a different server than the suite. With `DB_URL` set, in the environment or `server/.env`, the probe refuses by name: `artisan` follows it and the test suite blanks it, so there is no one server to measure. Each run prints the endpoint it measured. The address rule lives in `bin/lib/app-mysql-endpoint.php`, which `bin/env-mirror-diff.oracle.php` uses too, and `tools/ci-store-probe.selftest.sh` checks the `DB_HOST`/`DB_PORT` and `DB_SOCKET` cases and the `DB_URL` refusal against two private mariadbd instances. The CI lane, which exports a TCP address and no `DB_URL`, measures the same server as before.
