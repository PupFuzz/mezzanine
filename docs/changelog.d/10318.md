- **card#10318** — **The CI store check measures the same database the tests used.** `tools/ci-store-probe.php`, the MariaDB lane's outside check that a migration or the suite really wrote to the store, now takes its address from the app's own `mysql` connection, so `DB_SOCKET` and `DB_URL` reach it exactly as they reach the app; before, it built `host=DB_HOST;port=DB_PORT` itself, and on a socket-only private mariadbd it measured a different server than the suite. Each run prints the endpoint it measured. The rule lives in `bin/lib/app-mysql-endpoint.php`, which `bin/env-mirror-diff.oracle.php` uses too, and `tools/ci-store-probe.selftest.sh` checks the `DB_HOST`/`DB_PORT`, `DB_SOCKET` and `DB_URL` cases against two private mariadbd instances. The CI lane, which exports a TCP address, measures the same server as before.
