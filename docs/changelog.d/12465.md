- **card#12465** — **The reporter reads a line of its own call index once the line is complete, and never steps past it.** The flusher folds the index journal from a byte offset it saves in `index/snapshot.json`. When the unread end of a journal file was a line a hook was still writing, the offset moved past that line, so the reporter lost the call or subagent binding it recorded; a partial line carrying non-ASCII text after a complete one moved the offset by its character count instead of its byte count. The index-journal fold and the counter-sink fold now cut through one primitive that finds the last complete line in bytes and leaves a partial one for the next read. Reporter `0.6.1` (`fleet-reporter/UPDATES.md`). **Upgrade:** deploy the server (its `current_reporter_version` is `0.6.1`, so a seat on `0.6.0` shows the `update_required` badge until it upgrades), then on each seat pull the checkout and run `node fleet-reporter/install.js` with no arguments.
