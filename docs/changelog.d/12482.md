- **card#12482** — **The reporter's acceptance suite no longer fails at random on the check that nothing is sent while a pinned `ca_file` is missing.** The reporter behaves as its design says: the one pass already under way when the file goes builds its request on that pass's check, the request is refused while the file is missing, and it is sent once the file is back. The check had marked that pass's request as built after the removal whenever the pass took longer than a tenth of a second, which a busy machine does. It now reads where the missing-file period begins from the flusher's own log, and a new case removes the file while a pass is held between its check and its send. Nothing changes on a seat.
