- **card#12530** — **The PHP test suite keeps its database connection through a slow test.** The ingest sets a 10-second idle-transaction limit on its database session. A production request has a database session to itself, so the limit ends with the request. In the suite, a test's ingest request ran on the test's own session, and the limit stayed in force for the rest of the test. A test that then spent more than 10 seconds without a database statement, such as one driving the shipped browser modules on a slow CI runner, had its connection closed by MariaDB and failed with `2006 MySQL server has gone away`. The suite now puts the session's previous values back after every request. Running the server is unchanged.
