- **card#13794** — **A pull request that changes code must name its board card.** A new `dl-traceability` check fails a code PR whose title and head branch both lack a `card#<id>`, `card-<id>` or `DL-<n>` token; editing the title to add one re-runs the check with no push. Release (`release/`), back-merge (`sync/`) and Dependabot PRs pass without a token, as do PRs that change only documentation and fixes that name a `CVE-` or `GHSA-` advisory id. A second check, `dl-traceability-selftest`, runs the gate's own test suite against this repository's copy on every PR.
