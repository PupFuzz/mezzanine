- **card#12631** — **The reporter's acceptance suite runs its reporter processes on a clock the suite sets, so its timing checks no longer race a busy test machine.** A harness file, `fleet-reporter/fixed-clock.cjs`, is preloaded into the reporter processes the suite starts: a hook, the statusline, `selftest` and a one-pass flusher read one instant for their whole run, and a long-running flusher's passes, cadences and request deadlines move only when a case advances its clock, so a case waits for the process to go idle instead of sleeping and reads every interval off that clock; the seat write lock keeps the wall clock, as the reporter intends. Alongside it, the subagent-idle and `/clear` traces start a minute into an hour, so a run in an hour's last minutes no longer crosses into the next one; the concurrent-hook bursts' lock freeze covers the whole burst; the cases that read the shared test ingest read only their own seat's requests; the seat-write-lock case dates its live holder's lock ahead; and an installer check waits for a process to say it renamed itself rather than for half a second. The reporter itself is unchanged: no new version, nothing for a seat to apply. (`fleet-reporter/README.md` § Running the acceptance suite; `fleet-reporter/fleet-reporter.selftest.py` § 0.)
