- **card#12631** — **The reporter's test cases card#12631 names, and the ones found failing beside them, wait on what they test instead of on the clock.** The subagent-idle cases started their pinned clock on the wall clock, so a run in an hour's last minutes crossed into the next hour and the flusher removed the files the cases read; they now start a minute into an hour. The missing-`ca_file` cases waited for a log line the hook writes as well as the flusher, then for a fixed half second, and now wait for the flusher's own line. The concurrent-hook bursts could outlast their one lock freeze and start a real flusher, which then posted into later cases; each burst's freeze now covers it, and the cases that read the shared test ingest read only their own seat's requests. The counter sink's hour-roll case pinned its first hooks 200 ms before the hour, which a slow hook writes after, and now pins them a minute before. The flusher-ownership cases timed their quiet window from the flusher's launch, so a flusher slow to start read as one that sent nothing, and now time it from the flusher's first request. The seat-write-lock case dated its live holder's lock at the moment it wrote it, which a hook slow to start read as stale, and now dates it ahead. An installer check waited half a second for a process to rename itself and now waits for the process to say so. Other cases still time their checks by the wall clock, and a heavily loaded machine can still fail them; card#12631 lists them. Nothing changes on a seat.
