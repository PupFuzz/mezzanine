- **card#12631** — **The reporter's acceptance suite runs its reporter processes on a clock the suite sets, so its timing checks no longer race a busy test machine.** A harness file, `fleet-reporter/fixed-clock.cjs`, is preloaded into the reporter processes the suite starts: a hook, the statusline, `selftest` and a one-pass flusher read one instant for their whole run, and a long-running flusher's passes, cadences and request deadlines move only when a case advances its clock, so a case waits for the process to go idle instead of sleeping and reads every interval off that clock. The wrapped status line command's timeout, which node enforces on the wall clock, is widened to a hang bound on the test clock, so a slow machine's shell start-up no longer blanks the passthrough case; the suite's § 0 lists every such native timeout in the reporter and fails on a new one until it is classified. The seat write lock keeps the wall clock, as the reporter intends, and the P-5 latency samples run without the preload. The `/clear` traces now start a minute into an hour, as the subagent-idle traces already did, and the counter sink's hour-roll case pins its first hooks 200 ms before the hour again, which the fixed clock makes exact. The reporter itself is unchanged: no new version, nothing for a seat to apply. (`fleet-reporter/README.md` § Running the acceptance suite; `fleet-reporter/fleet-reporter.selftest.py` § 0.)
