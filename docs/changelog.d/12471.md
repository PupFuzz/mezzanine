- **card#12471** — **On Windows, the folder a reporter hook or the installer ran from can be deleted or renamed while the reporter's flusher runs.** The flusher started with the working directory of whatever started it and held that folder until it exited. The hook's respawn and the installer's Windows start now go through one spawn, which runs the flusher in the user's home folder. Ships in reporter `0.6.1` with card#12465: the same upgrade applies both.
