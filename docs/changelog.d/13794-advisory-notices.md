- **card#13794** — **Each dependency advisory the scheduled audit finds now gets its own GitHub issue, labelled `dependency-advisory`.** A new `Dependency advisory notices` workflow runs after each scheduled or dispatched audit on the default branch, reads the findings file each audited ref uploads, and opens one issue per advisory and package, updates it when the affected refs or versions change, and closes it when no audited ref reports the advisory any more. It creates the label on first use and runs on the repository's own token. Setting the repository Actions variable `DEPENDENCY_AUDIT_NOTICES` to `off` turns it off and stops the audit uploading its findings file. The `dependency-audit-selftest` check now also runs the notices workflow's two test suites on every PR.
