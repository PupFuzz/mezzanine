- **card#13117** — **A floor's web address is now its name, and a room nobody has placed is drawn on one Unassigned floor.** Every floor in the building layout carries a required `name` (the member `label` is refused, naming the edit), and its address is the slug of that name — The Burrow is at `/floor/the-burrow`, with accents folded and any case typed reaching it; a floor's `aliases` keep the addresses it had before a rename, so an old link redirects in one hop, and a link naming a room still reaches the floor that holds it. A room the layout does not place — a new room, or the seats in no room — is drawn on the Unassigned floor, last in the directory and the cab, until the operator places it. The upgrade's migration names every floor of the stored layout after its label (else its old key), keeps each old key as an alias, and places every reporting room the layout did not place on a floor of its own, so no floor's content changes; the directory's order and numerals change once, as floors now sort by their new addresses.
