- **card#13794** — **Every PR body now declares where its change came from, and the PR-body check judges it with the linter already on the target branch.** A PR body needs an `Origin:` line (`bin/change-pr-body.py --origin` writes it, with `--design-approved` for an agent-originated change), and a PR that edits `bin/pr-body-lint.py` is judged by the base branch's copy. The PR-body linter, its selftest and the dependency-advisory audit follow coord 0.79.0: the linter accepts `Origin: refactor card#<n>` for a change with no behaviour change; the audit reads comma-separated advisory ranges whose pieces share no version as either-or, names a 404 or 403 on a reviewed-record lookup, and passes a repository whose lockfiles are all of an ecosystem its second source does not read when it names them. The dependency audit opens no pull requests: it checks both branches nightly and reports every advisory. Every pull request runs a storage-cost guard: each CI upload keeps its files two days or less and states why it exists, and each cache key changes when its inputs do.
