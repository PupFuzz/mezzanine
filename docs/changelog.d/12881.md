- **card#12881** — **Every link Mezzanine emails, redirects to or renders uses the site's configured address (`APP_URL`), whatever host a request names.** The two-factor reset email built its *Enter the code* link from the incoming request's `Host` header, so on a web server that passes unknown hosts through to the application, a reset requested with a forged `Host` mailed the account's owner a link to the forger's host. The URL generator is now pinned to `APP_URL`'s scheme and host at boot, which covers the reset link, every redirect, and every page's form actions, stylesheets and scripts, in web requests and in console and scheduled commands alike. A browser that reaches the site at another address follows its links, forms and redirects onto `APP_URL`'s. The application refuses to start, naming `APP_URL`, when it is not an `http://` or `https://` address with a host, because such a value would have left links following the request's host again.
