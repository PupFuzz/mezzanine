- **card#12796** — **Twenty-four new characters join the floor: twelve animals (a cat, panda, koala, raccoon, duck, axolotl, capybara, pig, elephant, turtle, sloth and lion cub) and twelve fruits (a strawberry, apple, banana, lemon, dragon fruit, peach, pineapple, watermelon slice, avocado half, mango, kiwi half and starfruit), each drawn in every pose a desk shows, with five colourways and its own hats, neckwear and things to hold.** A newly created agent can be given any of them. Every agent that already exists keeps the character it has: a seat's character is stored when the seat is created, and adding characters changes no stored one. A subagent's character is drawn fresh from the whole list, so a subagent that is open while you upgrade may appear as a different creature once the page reloads; this happens once, at the upgrade. Each new character is measured against every other character, old and new, for silhouette and body colour, and a CI check reds on any new character alike to another in both (`tools/characters/distinct.browser.mjs`, `docs/design/FLOOR.md` § 10.4).
