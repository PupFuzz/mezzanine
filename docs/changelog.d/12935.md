- **card#12935** — **Each change now carries its own changelog note, so changes built side by side no longer conflict on `docs/CHANGELOG.md`.** A change PR adds one file, `docs/changelog.d/<card>.md`, holding the bullet exactly as the CHANGELOG will show it, and leaves `docs/CHANGELOG.md` alone; the release PR runs `python3 bin/changelog-fragments.py assemble --date <merge date>`, which writes the version's section under `## [Unreleased]` from every note, highest card number first, and deletes the notes. `release-pr-guard` enforces both halves: R4 now asks for the card's note in `docs/changelog.d/` rather than a bullet in the CHANGELOG, R8 refuses a change PR that adds a line under `## [Unreleased]` or carries a malformed note, R9 refuses a release PR that leaves a note unassembled, and R6 accepts the release deleting a note only when that note's exact line is in its CHANGELOG. The notes that were under `## [Unreleased]` moved into `docs/changelog.d/` unchanged, one file each. **For an open PR built before this change:** move its bullet out of `docs/CHANGELOG.md` into `docs/changelog.d/<card>.md` when it next takes in `dev`.
