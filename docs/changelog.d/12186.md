- **card#12186** — **A user can forget one remembered browser, or all of them, from the recovery codes page, without changing their password.** A new **Remembered browsers** section lists the account's own remembered browsers by name (for example "Firefox on Linux"), with when each was remembered and when it expires and the current browser marked; **Forget** and **Forget all** make the next sign-in on that browser ask for a code, and leave the current session signed in. The upgrade's migration adds a `label` column to `remembered_browsers`; a browser remembered before the upgrade is listed as "Browser remembered on <date>".
